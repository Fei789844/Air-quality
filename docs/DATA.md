## 数据来源及地理位置

[UCI Air Quality](https://archive.ics.uci.edu/dataset/360/air+quality) 提供意大利某城市的污染物浓度与传感器响应。当前仓库没有可以确认监测站为罗马的定位信息。

原报告将 [Open-Meteo](https://open-meteo.com/en/docs/historical-weather-api) 作为气象数据来源。`Rome_meteo.csv` 元数据给出纬度 41.862915、经度 12.539912、海拔 54 米，时区为 GMT、UTC 偏移为 0。原始下载请求和具体天气模型未随仓库保存。

Notebook 直接按无时区的小时字符串合并。污染物文件没有时区声明，整理时保留了原处理方式；跨来源的时区及夏令时对齐需要在进一步预测实验中确认。

## 字段和预处理

| 变量 | 原始单位或含义 | Notebook 中的处理 |
| --- | --- | --- |
| `CO(GT)` | mg/m³ | 转为数值；代码未统一转换为 µg/m³ |
| `NMHC(GT)`、`C6H6(GT)`、`NO2(GT)` | µg/m³ | 转为数值 |
| `NOx(GT)` | ppb | 乘以 1.88，作为项目中的近似换算 |
| `T`、`RH`、`AH` | 温度、相对湿度、绝对湿度 | 作为解释变量 |
| 降水、云量、10 米风速、辐射、海平面气压、浅层土温 | 单位见列名 | 从 Rome 文件按小时连接 |
| `weekday`、`is_holiday` | 星期与意大利节假日标记 | 日历特征 |
| `AQI_lag_24h`、`AQI_lag_168h` | 目标的历史滞后 | 分别调用 `shift(24)`、`shift(168)` |

UCI 用 `-200` 表示缺失值；Notebook 对选中的数值列将 `<= -100` 设为缺失。自定义 AQI 先对五种污染物做分段线性映射，再取可用分指数最大值。目标序列随后按时间插值，参数包括 `limit=7`、`limit_direction='both'`；SARIMA 分支还补齐小时网格并再次插值。

分段阈值见 Notebook 的 `AQI_BREAKPOINTS`。原报告引用的 `01_Tableau-Normes-Seuils réglementaires.pdf` 未包含在当前仓库，所以此指数按项目自定义指标解释。代码并未完整实现某个已核验的官方 AQI 标准。

## 使用与署名

UCI 页面提供数据集引用与许可信息，附加说明写明研究用途、排除商业用途；使用前应查阅[原页面](https://archive.ics.uci.edu/dataset/360/air+quality)的当前条款。气象数据请按 [Open-Meteo](https://open-meteo.com/) 的来源要求署名。本次整理保留仓库中已有数据，未引入新数据副本。

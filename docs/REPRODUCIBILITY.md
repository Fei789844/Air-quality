## 执行原 Notebook

按 README 创建环境、安装依赖后，从仓库根目录运行 `jupyter lab`，打开 `AirQuality中文版_.ipynb`。其 `os.getcwd()` 用来寻找两份输入 CSV，因此执行内核的工作目录应为仓库根目录。

Notebook 包含耗时的 SARIMA 拟合和深层神经网络训练。Keras Tuner、Optuna 的部分搜索语句处于注释状态，已有超参数直接写在代码中；正常阅读和使用已保存参数不需要恢复搜索。训练权重与原调参目录没有随仓库保存，执行训练单元格会重新拟合。

现代 pandas 对旧式 `asfreq("H")` 和 datetime `.view('int64')` 的兼容性可能不同。新环境若报错，应先记录环境版本，再调整对应 API。请在副本中执行并另存结果，便于与原保存输出比较。

## 评估设置

主体切分按时间顺序取约 60% 训练、40% 测试，部分代码在切分点加 1 行。不同分支会重新筛选缺失值或补齐时间网格，因此不是统一的测试样本集合。

| 分支 | 预测时使用的信息 | 验证方式 |
| --- | --- | --- |
| SARIMA | 已观测目标历史；预测后用真实观测 `extend` 更新状态 | 滚动一步预测 |
| SARIMAX | 测试期真实外生变量与预先构造的历史滞后特征 | 从训练末端一次预测整个测试区间 |
| 树模型 | 每个测试时间点的真实气象及滞后特征 | 测试集也用于比较超参数 |
| MLP / LSTM / GRU | 对应分支的气象、日历和滞后特征 | 测试集也用于 early stopping / 调参 |
| 补充 GRU | 24 步输入窗口、周期编码、RobustScaler、差分特征 | 独立构建训练及测试窗口，测试集用于训练监控 |

主 LSTM / GRU 分支把输入 reshape 为 `(samples, 1, features)`，每个样本只有 1 个时间步；补充分支才显式构造 24 步窗口。补充分支新增 `AQI_diff`，训练搜索函数与最终拟合使用的数组也需要逐处核对。

目标插值在切分前进行且允许双向填充；历史数据里的缺测修复可以使用后续观测。因而保存指标对应这份离线实验。要评估实时未来预测，需要按预测时点限制可用信息：只用当时可取得的数据处理缺失，提供对应提前量的天气预报，明确递归滞后更新方式，并留出独立验证集和最终测试集。
